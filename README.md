# Portfolio

Персональный сайт-портфолио с учебными и пет-проектами.

## Сайт
- [levinadev.github.io](https://levinadev.github.io)

## Технологии
- Python 3
- Flask
- Jinja2
- Bootstrap 5

## Локальный запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```

После запуска откройте:
- http://127.0.0.1:5000/
